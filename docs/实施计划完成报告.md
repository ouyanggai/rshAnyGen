## 📋 使用指南

### 访问Token监控
1. 登录系统 (需要admin权限)
2. 访问: `http://localhost:9300/admin/tokens`
3. 查看实时监控数据

### API调用示例
```bash
# 获取Token使用统计
curl -H "Authorization: Bearer <token>" \
  http://localhost:9301/api/v1/metrics/token-usage

# 获取延迟统计
curl -H "Authorization: Bearer <token>" \
  http://localhost:9301/api/v1/metrics/latency
```

### 查看Redis中的指标
```bash
# 连接Redis
redis-cli -h 192.168.1.248 -p 6379

# 查看指标列表
KEYS metrics:*

# 查看具体指标
LRANGE metrics:latency:chat_response 0 10
```

## 🔧 技术实现

### 指标存储结构
```
Redis Keys:
├── metrics:tokens:operation          # Token使用记录
├── metrics:latency:context_build      # 上下文构建延迟
├── metrics:latency:chat_response      # 聊天响应延迟
├── metrics:context:token_budget      # 上下文Token预算
├── metrics:context:layer_usage        # 上下文层级使用
├── metrics:memory:entity_extraction   # 实体提取
├── metrics:memory:retrieval           # 记忆检索
├── metrics:memory:deduplication       # 记忆去重
└── user:active_session:*             # 活跃会话
```

### 数据保留策略
- 每个指标保留 **1000条** 记录
- 支持 **1小时-3天** 时间窗口查询
- 自动清理过期数据
